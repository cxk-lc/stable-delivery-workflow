2. **每次改动后必须编写或更新相关测试**，并在交付前确保所有测试与验收全部通过。
3. **所有 Git commit 信息统一使用{{COMMIT_LANG}}**（初始化时确认，如需变更请同步修改本文件）。
4. **不提交密钥与敏感数据**：不要提交 `.env`、密钥、客户数据；配置示例写入 `.env.example`。
